Profile claims

A student asked to own a profile moved from the old site. Approve only when you are satisfied it is them: a similar name or GitHub handle is not proof.

    Import legacy data

    Choose the legacy export (for example legacy_export.json) or the scale fixture. Importing the same file again is safe: records already imported are skipped, not copied.

    The file is read in your browser and sent to the server. Nothing is published that the file does not already mark as published.

    Import history

      Profiles

        Merge duplicate profiles

        The duplicate's contributions, skills, collaboration links and requests move to the surviving profile. Its old address then leads visitors to the surviving profile.

        Duplicate partners

        Collaborations and project links move to the surviving partner, and the duplicate's public page points to it.

        Project maintainers

        When a maintainer has left, choose another accepted contributor. The project keeps its address, contributors and history.

          Diagnostics

          Failed integrations and server errors (no passwords, codes or cookies are recorded), and every ownership, merge and status change.
